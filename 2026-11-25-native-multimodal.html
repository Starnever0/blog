Technical Map · Multimodal Foundation Models

原生多模态 从拼接、对齐到"出生即多模态"——五条技术路线、一张架构解剖图，以及区分"真原生"与"营销原生"的判据。

"原生"目前没有统一标准。本文以 2026 年 5 月的 NMM 路线图综述为骨架[1]，用其形式化定义把融合深度排成 late / mid / early 三档（late 作为被明确排除的基线），再叠加输入—输出对偶（M2T / M2G / M2M）做二维定位，最后用 457 个模型的 scaling law 实验[2]回答那个最实际的问题：早融合到底值不值。

JUDGEMENT 01

"原生"是可形式化的，
不是形容词

按 Fearly = Transformer(∪ T(mi))，只有统一 tokenizer + 单一主干才算 born-native；mid-fusion 是过渡态；late-fusion 被明确排除在 NMM 之外[1]。

JUDGEMENT 02

早融合不天然更强，
但更便宜

同 compute 下早/晚融合的验证损失几乎重合（L ∝ C−0.049 vs C−0.0494）；优势集中在低参数量与部署成本，而非上限[2]。

JUDGEMENT 03

真正的分歧在
理解—生成两难

全离散统一要交感知信息税；双编码器解耦保住了感知，代价是参数与对齐复杂度。这是当下 M2M 路线的主战场[1][3]。

00

三档融合深度：把"原生"拆成可判定的结构

判据只有一条：主干是否直接以原始模态信号为输入。凡是先经独立编码器再注入主干的，无论训练得多联合，结构上仍属 late 或 mid，不是 born-native。

易混淆点："原生"在厂商口径里至少有三种含义——① 预训练数据从一开始就含多模态（数据层面）；② 单一主干、无独立编码器（架构层面）；③ 单一模型同时理解和生成（能力层面）。三者互相独立。一个 mid-fusion 模型可以同时满足 ① 和 ③，但按结构定义仍不是 born-native。判断时先问是哪一层。

01

谱系：五条路线不是替代关系，是并行下沉

纵向是年份，横向是路线。注意 2024 年之后的变化——新模型不再"取代"旧范式，而是把旧范式的产物（预训练视觉塔、对比学习表征、扩散解码器）当作组件吸收进统一主干。

把谱系竖着切，每一刀都是当时的最优解
2021
对齐到同一表征空间

当时没有能吃的多模态主干，最优解只能是 CLIP 式图文对齐——先把两个模态放进同一个空间，任务本身留到下游做。

2022 — 2023
别动主干，只加接口

重训主干太贵。Flamingo 插交叉注意力、BLIP-2 加 Q-Former、LLaVA 加两层 MLP，都在解同一道题：怎么便宜地接上去。

2024 —
为共享梯度付学费

算力与数据同时到位，早融合才从"不划算"变成"可以试"——是可行域被成本结构推开，不是范式说服了谁。

所以这几条路线不是教科书式的范式更替，而是成本结构变化导致的可行域扩张。今天 mid-fusion 仍然是绝大多数生产系统的选择，原因不在技术落伍，而在它把"视觉能力"做成了一块可替换、可独立升级的零件。

一个规模证据：2025 年 11 月的 Gemini 3 Pro 模型卡把"原生多模态"写成了架构事实——稀疏 MoE、文本/图像/音频/视频统一输入、1M 上下文，并明确声明"不是前代模型的微调"[15]。这是目前公开可查的最大规模早融合部署声明，但具体融合方式与视觉接口形态仍未披露——也正因如此，它无法被归入任何一张谱系图的确定位置。

02

五条流派的机制差异

每一行对应一种"把视觉塞进语言模型"的解法。看三件事就够：接口放在哪、梯度流过谁、信息在哪一步有损。

投影器桥接（BLIP-2 / LLaVA 一系）在 2023—2025 年的产业界长期占优，最根本的原因是什么？

  • A表征对齐效果优于交叉注意力注入

解析

03

架构解剖：五个可替换部件，五个代价点

不同路线吵得最凶的其实不是"要不要原生"，而是这五个部件怎么选。每个部件只有两个主流答案，且每个答案都带一条结构性代价——没有同时最优的组合。

一个反直觉的细节：Janus 系列的解法不是"选一边"，而是装两套视觉编码——理解用 SigLIP 的连续特征，生成用 VQ 的离散 token，两路各自进同一个 Transformer，输出侧按任务切换[3][13]。这直接承认了"一套表征同时服务理解与生成"在当前技术下不划算，用参数换解耦。
CHECK 03单选 · 点击选项即判

Janus 用两套视觉编码器：理解走 SigLIP 连续特征，生成走 VQ 离散 token。这个设计在机制上等于承认了什么？

  • A单一表征同时服务理解与生成在当前技术下不划算，于是用参数换解耦
  • B扩散头可以被纯自回归完全替代
  • C离散 token 的生成保真度已经超过扩散
  • D视觉编码器越多，跨模态耦合越深
解析

理解要连续高保真特征，生成要离散可预测 token，方向相反——这就是"理解—生成两难"。Janus 没有解决两难，而是绕开它：装两套编码，输出侧按任务切换，代价是参数与对齐复杂度。

04

训练范式：融合深度决定训练签名

同一个五阶段流水线，mid-fusion 与 early-fusion 在每一步的做法几乎相反。这不是调参差异，是"能不能单独动某一块"的结构性差异。

最值得记住的一条：早融合把"训练制度"从可调变成了几乎不可调。mid-fusion 出问题时你能换冻结策略、换投影层、单独重训视觉塔；early-fusion 出问题时你只能改数据配比和损失权重，然后整跑一遍。这就是为什么它的试错成本高一个量级——不是算力贵，是可观测性和可控粒度都没了。

早融合的试错成本比 mid-fusion 高一个量级，直接原因是什么？

  • A单步训练的算力开销更大
  • B需要更多人工标注的图文对
  • C冻结拓扑与损失结构不可单独调整，出问题只能改数据配比后整跑一遍

解析

05

选型：按负载形态走，而不是按"是否原生"走

"要不要上原生"这个问题问错了。正确的问法是：我的瓶颈在感知精度、生成保真度，还是端到端延迟。三个答案指向三条不同的路。

场景推荐范式主要瓶颈判断依据
文档 / 图表理解mid-fusion分辨率与 token 预算瓶颈在视觉编码器的有效分辨率，不在跨模态耦合深度。动态分辨率 + 视觉 token 重采样收益远大于换架构。
GUI / 屏幕 Agentmid-fusion定位精度、时序需要精确坐标与元素级 grounding，成熟检测/定位头比端到端更可控；早融合在细粒度空间定位上并无优势。
长视频问答mid-fusion 待观察序列长度、位置编码瓶颈在 3D 位置编码与帧采样策略；早融合的全序列注意力在这里是负担而非优势。
图文交错文档生成early-fusion统一词表、生成保真只有共享词表的模型能"边写边画"且保持上下文一致；这是 late/mid 在结构上做不到的事。
创意图像生成 + 编辑AR + 扩散视觉保真度纯离散 AR 的图像质量仍落后扩散；Janus 式解耦用参数换质量，是当前最稳的工程解。
实时语音对话全模态流式端到端延迟要压到百毫秒级，必须做全双工 + 流式 token 输出，架构上更接近 Moshi / Omni 系而非 VLM。

文档 / 图表理解场景，为什么推荐 mid-fusion 而不是 early-fusion？

  • A因为 early-fusion 的推理延迟一定更高
  • B因为 early-fusion 无法处理超过一万 token 的输入
  • C因为 early-fusion 在该场景还没有任何公开实现

解析

选型看瓶颈位置，不看"是否原生"。文档场景的损失主要来自视觉信息在进主干之前就被压掉，这是分辨率与 token 预算问题，换融合深度解决不了。同理，GUI Agent 的瓶颈是定位精度，长视频的瓶颈是 3D 位置编码。

06

关键词卡

读这一带文献时反复出现的十二个词。按"会改变你读论文的方式"排序。

Early fusion
所有模态先经统一算子映射到同一空间，再由单一 Transformer 处理。标志：没有独立视觉编码器，词表里图像与文本是同一批 id。
Mid fusion
保留模态编码器，把跨模态对齐做成算子注入主干中间层。结构上仍不对称，但已非事后对齐。
Modality gap
对比学习训出的图文表征虽对齐，却分布在嵌入空间的两个不相交锥体内。它是 late fusion 需要投影层的根本原因。
Codebook / VQ
把连续图像压成有限码本索引。码本大小决定信息上限，下采样率决定 token 数——两者共同构成"信息税"。
Q-Former
BLIP-2 的可学习 query 集合，用固定数量 query 从视觉特征里"抽取"信息。本质是固定带宽的信道。
Perceiver Resampler
Flamingo 的变长→定长压缩模块。与 Q-Former 目标相似，但服务于层间交叉注意力的输入。
Gated cross-attention
门控初始化为 0，使新增层在训练初期等价于恒等映射。保护预训练权重不被随机初始化破坏。
双损失
文本走交叉熵、图像走扩散/流匹配，同一主干两套梯度。难点不在实现，在配比与梯度尺度。
MoT
Mixture-of-Transformer-Experts：理解与生成各用一组专家，共享注意力。BAGEL 的做法[12]。
TMRoPE
把位置编码拆成时间、高、宽三轴，使音视频与图像共享同一套时序语义。Omni 系的关键件。
理解—生成两难
理解要连续高保真特征，生成要离散可预测 token，二者对表征的要求方向相反。当前没有单一表征同时满足。
Grounding hack
RL 阶段模型绕过视觉证据、直接从语言先验"猜"答案，指标虚高。早融合尤其容易中招。
CHECK 06单选 · 点击选项即判

"Modality gap"与投影层之间是什么关系？

  • A投影层训练不足造成了 modality gap
  • B两者无关：前者是数据问题，后者是架构问题
  • Cmodality gap 是 late fusion 必须加一层投影的根本原因
  • Dmodality gap 只出现在离散 token 模型里
解析

对比学习只保证配对样本在空间中相近，不保证两个模态的分布重叠——图文表征落在两个不相交的锥体里。既然不在同一空间，就必须有一层可学习的翻译把视觉特征"搬"进词嵌入空间。投影层是 gap 的结果，不是原因；也因为它是唯一的通道，所以它天然是信息瓶颈。
