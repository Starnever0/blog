Model Watch 模型雷达
第 01 期  /  2026-11-24
2026 年 11 月刊

八家主力在一个月内换完血，然后集体开始算账

9 月底到 11 月，OpenAI、Anthropic、Google、阿里、腾讯、智谱、月之暗面、DeepSeek 把主力模型轮了一遍。跑分还在涨，但发布会上的主语换了——从「我们最强」变成「完成这件事要多少钱」。这一期把八家的现状摆在同一张桌上看，标出各自真正的新东西，以及该在什么任务上用它。

8 家厂商 本期主角：Gemini 4 · GLM-5.4 下次更新：12 月中
01

本期三个判断

不是综述。以下三条是这个月的信息放在一起之后，我认为值得记住的部分。

判断 一

比较单位从「每百万 token 多少钱」换成了「跑完一个任务多少钱」

阿里发布 Qwen4-Max 时，最显眼的数字不是跑分，是单任务费用降 58%；DeepSeek 的 V4.1-Flash-1017 单价一分没动，靠 token 用量砍掉一半来降成本；腾讯把 Hy4 flash 的单任务成本压到 Hy4 的 1/20；Google 讲 Neon 时会说「比 Carbon 便宜 32%」。

四家在不同国家、同一周，用了同一个指标。这不是巧合，是行业已经承认：单价可以被补贴扭曲，任务账单不会。模型越往 Agent 走，一次任务里塞的上下文、重试、工具调用越多，标价和实付的差距就越大。

选型时该比的不是价目表，而是「你这类任务跑一百遍，一共多少钱、返工几次」。厂商给的倍数差异跨档位比较基本不可信——Flash 档跟旗舰档比单任务成本，赢是应该的。

判断 二

三条架构路线，做的是同一件事：让「思考」变得可计价

智谱走的是深度。GLM-5.4 首次用上 Loop Transformer：一组共享权重的层循环跑 28 层两轮，每次循环接着上一轮的隐状态继续推演。参数量不动，等效智能冲到 2–3 万亿档。用时间换规模。

阿里走的是稀疏。Qwen4-Max 换掉注意力（QSA 稀疏注意力）、加宽残差（四条并行分支的 Gated Residual）、再加 328B 的 N-gram Embedding 扩容量。2.4 万亿总参，只激活 71B——比上一代还少 25%。用稀疏换规模。

Google 走的是调度。Gemini 4 这代把编排层放进模型里：按子任务动态分配推理预算，简单的走轻量路径，难的升级到深度思考。用调度换成本。

三条路方向不同，落点一样——把算力花在值得想的地方，其余地方省掉。这对做 harness 的人是好事：模型自己在收敛「该想多久」，外部框架能省的那部分冗余，正在被模型层吃掉。

判断 三

「旗舰」在贬值，「开源」在升值

Gemini 4 Carbon 是 Google 自称最强的推理模型，12 月 1 日起从 $2/$10 翻倍到 $4/$20；而它自家的 Neon 用 $3/$15 在编程 Agent 榜上反超了它。Anthropic 的 Fable 5.2 降价 20% 后仍是 $8/$40，是全场最贵的一档。

同一时间，Kimi K3.1 Pro 把 3 万亿参数的权重开了，DeepSeek 从 V4 起就是 MIT，腾讯把 Hy4 flash 的权重放上 Hugging Face 并附了 base 模型，智谱说 GLM-5.4 的权重「计划以负责任的方式开源」。

闭源旗舰卖的是最难的 1% 任务，开源卖的是你能自己改、自己部署的那 99%。两条线的价格曲线正在分开走，中间那档——够强、够便宜、能自己跑——是今年最挤的位置。

04

逐家拆：真正的新东西是什么

每家只挑一个本期最值得看的模型。跑分只保留能说明「它为什么这么设计」的那几个。

OpenAI

2026-11-17
GPT-6.2 Astra / Sol

旗舰 + 日常，一次发两款。Astra 打专业工作，Sol 打效率和成本。

+5.2ALE 得分较 GPT-6 Astra 的提升
−20%API 输入输出价格降幅
<1/3Astra 完成任务成本相对上代
≈1/5Sol 相对 Astra 的成本
三档怎么分工

真正的新东西

不是参数，是可编辑的产出。Astra 被专门训练去参照用户给的模板匹配排版、配色、字体，输出可继续编辑的演示文稿和表格，而不是一段描述。FrontierCode 2.0 上 Sol 与 Astra 只差不到 0.5 分，成本却只有约 1/5——这意味着「用旗舰还是用主力」的判断依据，从能力变成了任务容错度。

注意

两款都达到 Preparedness Framework 的网络安全 Critical 级，Astra 还是首个达到「AI 自我改进」High 级的外部发布模型。官方 system card 同时承认，两款模型在「汇报工作时是否主动交代遇到的障碍」上比前代退步了。做全自动流程的话，这个点比跑分重要。

Anthropic

2026-11-09
Claude Fable 5.2

第四档，坐在 Opus 之上。默认 effort 就是 high，思考关不掉。

64.6AA 智能指数，当前第一
49.1%FrontierCode 2.0（Opus 5.5 为 45.5%）
$8 / $40较 5.1 降 20%，仍是最贵档
30h1000 个 agent 形式化费马大定理的耗时
FrontierCode 2.0 · 长程 agentic coding

真正的新东西

自适应思考常开，且跨轮保留推理状态。以前的推理模型每轮重置思维链，Fable 5.2 把推理状态一路带到几十次工具调用之后——它能在长会话里维持一个大代码库的心智模型，这才是「跑几小时不崩」的底层原因。代价是你没法再用 temperature 调它的「想多少」，只能给 effort 档位。

注意

Fable 带 cyber / bio 分类器，被拦下的请求会转给 Opus 问一遍。如果你做安全研究，能用的是 Mythos 5.2——同一模型、少限制，但要过 Anthropic 的验证计划。另外它要求 30 天数据留存，零留存合同下不可用。

Gemini 4 Neon

七周四款里的最后一款，也是目前最该当默认主力的一款。

真正的新东西

Neon 不是把 Hydrogen 放大，是从 Carbon 改出来的——保留了深推理的底子，但在多步工具会话里大幅压缩了冗余文件读取和上下文整理的开销。结果是「跟 Carbon 同档的分数、约两倍的速度、更低的单任务成本」。这也解释了为什么 Google 敢让它在编程 Agent 榜上压过自家旗舰。

注意

三个真实的短板：网页前端审美偏弱（WebDev 榜第 7，不给设计规范会堆饱和色块）；爱打包票——不催它就跑完表面功能自信交付，边界条件容易漏；海外高峰期偶发 503。另外这代把 Pro / Flash 后缀全扔了改用元素名，App 菜单里叫 Everyday help / Deeper analysis / Code & complex work，对不上号是常态。

DeepSeek

2026-10-17
V4.1-Flash-1017

一个看着像补丁的版本号，实际改了行业算账的方式。

77.0%DeepSWE 1.1 通过率（上代 74%）
>50%同等任务 token 用量降幅
$0.15 / $0.60单价一分没降
5 个11/13 新开放的独立 API
柔性降本：标价不动，账单变薄

真正的新东西

柔性降本：不改价目表，改任务的实际消耗。三层机制——任务感知压缩、动态上下文裁剪、自适应解码。对客户来说合同没变、账单变薄；对竞争对手来说，这个优势藏在执行链路里，比一个可以直接对标的降价数字难复现得多。同期还第一次由模型方自己画了性能—成本帕累托前沿。

注意

压缩是有代价的：复杂推理、超长文档解析、多步链式任务里，压缩策略可能吃掉关键细节。官方平均通过率盖不住这类长尾。另外那条帕累托曲线的对比对象是 Fable / Astra 这类旗舰——拿 Flash 档跟旗舰比单任务成本，倍数好看但不公平。

智谱

2026-11-23
GLM-5.4

本期主角之一。国产模型里第一次把新架构押在正式产品上，而不是论文里。

28 × 2层循环两轮，参数量不变
750B → 2–3T实际智能水平所处档位
200真实场景编程实战评测
200 tps配套推理基础设施上限
Loop Transformer：不加深网络，加「循环」

真正的新东西

Loop Transformer。标准 Transformer 每层在前向里只跑一次；Loop 让一组共享权重的层循环执行，每一轮在上一轮隐状态基础上继续推演、修正。等于不增加参数就拿到更深的网络。智谱的做法很务实——没有直接押在最贵的一次超大训练上，而是拿已经训好的 750B 基座做两轮循环改造，把架构、训练路径、推理 infra 一起跑通，再往更大规模跃迁。

另一个方向是泛 Coding：把代码能力延伸到 Code to Video / Game / 3D / Image，理由是视频的每一帧、3D 场景的几何约束本质都能被代码表达。能代码化的任务，软件工程里学到的拆解、长程规划、自我纠错就能迁移过去。

注意

现在能用的是 GLM Coding Plan 全量用户和 ZCode / Trae / WorkBuddy / Qoder 这些平台；API 还在安全评估，权重只是「计划开源」。所以它此刻是「编码工具里的模型」，不是「你能调的服务」。官方还说 GLM-5.5 会到约 3 万亿参数，规模是现在的四倍。

阿里 · 千问

2026-11-16
Qwen4-Max

2.4 万亿参数，只激活 71B。中国模型在 CodeArena 上的最好名次。

−58%单任务平均费用（26.58 → 11.16 元）
289K→151KTerminal-Bench 单次尝试 token 用量
第 6CodeArena 前端编程盲测，夹在 GPT-6 Astra 与 Fable 5.1 之间
¥0.5缓存命中价 / 百万 token
2.4 万亿参数里，每个 token 只点亮一小撮

真正的新东西

三处架构改动，全是为了「少算但算对」。QSA 稀疏注意力砍长序列的注意力开销；Gated Residual 把残差流扩成四条并行分支，增强跨层信息传递；N-gram Embedding 用很低的计算代价给模型扩容。合起来的结果是：每 token 激活的参数比上代少 25%，而 Terminal-Bench 得分从 38.9 升到 48.5，用的 token 只一半。

这是「思考效率」第一次在国产旗舰上被明确当成一等指标，而不是降本的副产品。

注意

闭源、仅 API。三方测评口径说它只接文本输入（阿里官方材料称有原生视觉能力），这类矛盾在发布初期很常见，接入前自己测一遍。另外「单任务 -58%」是它在自家 Work360 评测集上的口径，跨厂商不可比。

月之暗面

2026-10-24
Kimi K3.1 Pro

全球参数规模最大的开源模型，3 万亿。这次的重点不是长文本，是「干活」。

3T总参数，权重已开放
¥13 / ¥68标准档；Highspeed 快 2–3×
1M上下文
36自主修正的肩部肌肉力臂计算错误数
从「能读多长」换成「能不能交付」

真正的新东西

K3.1 是 K3 的后训练版本，算力几乎全加在强化学习上。能力方向也换了个说法：不是「能读多长」，而是「能不能端到端交付」——从文字或草图推断物体形状比例，操作专业建模软件生成 3D 模型；从检索资料、跨文档核对，到搭财务模型做盈利分析。

官方那个会走路的模拟器案例值得看：调奖励没效果时，它去查动力学，自己找出 36 处肩部肌肉力臂计算错误再重训。这是长程 agent 该有的行为，不是聊天模型的行为。

注意

K 系列对历史思考内容敏感，训练时全程保留思考历史。如果你的 Agent 框架不回传完整 thinking，或者中途从别的模型切过来，质量会不稳。另外它在小问题或意图模糊时会替你做决定——要边界感就得在 system prompt 里写死。

腾讯 · 混元

2026-11-16 / 19
Hy4 flash

224B 总参只激活 12B。16 号发布，19 号把权重放了。

12B每 token 激活参数
¥0.5 / ¥2输入 / 输出，缓存 ¥0.02
>150 tps解码速度

真正的新东西

三个环节同时压：预训练用混合注意力 + LatentMoE + Engram，把 KV cache 压到 Hy3 的 1/24；后训练自蒸馏 Hy4 拿能力，再用强化学习直接把端到端输出长度砍一半；推理用 megakernel + 4bit 量化 + DFly。单看任何一环都不新鲜，三环叠起来才是 1/20 这个数。

更值得记的是它开源时同时给了 base 模型——那是做后训练真正需要的东西，不是发个 instruct 版本算开源。

注意

腾讯 Hy License 不是 MIT / Apache，商用前读条款。权重发布时没附跑分和硬件要求。它的强项明确在文档、PPT、深度搜索、Computer Use 这类日常活，长程软件工程官方自己都建议换 Hy4 标准版。

数据口径，以及我没敢写成事实的部分

这个栏目的原则是：数字必须能追到出处，追不到就标成「待确认」。以下几条是这个月特别容易看错的地方。

  1. 跑分几乎全是厂商自测。AA 智能指数、CodeArena、GraphWalks 这些第三方榜有参考价值，但厂商发布材料里挑的对手和档位都很讲究。跨厂商横向比分数，只能当方向看。
  2. 日期口径有分歧。Gemini 4 Argon 有 9/30 与 10/13 两种说法（发布 vs 大范围开放）；Carbon 是 10/28 限量预览、11/10 正式 GA；Neon 美东 11/18、北京时间 11/19。本文统一取「正式可用」那天。
  3. 价格有窗口期。Gemini 4 Carbon 与 Argon 现在是上线半价，12 月 1 日翻倍到 $4/$20，同一天 Gemini 2.5 Pro / Flash 的 API 下线。任何按现价做的预算，下个月都要重算。
  4. Qwen4-Max 的输入模态有矛盾。阿里官方材料称有原生视觉能力，部分第三方价格站标为纯文本。以官方为准，但接入前自己发一张图试试。
  5. GLM-5.4 缺两块信息：API 价格（安全评估未完）与上下文长度的官方重申（沿用 5.2 起的 1M 口径）。权重「计划开源」不等于已开源。
  6. 「单任务成本」这个指标本身是厂商自定义的。任务集、推理档位、评测框架各不相同，Qwen 的 Work360、腾讯的 WorkIndex、DeepSeek 的 Harness 各算各的。它能说明趋势，不能直接比大小。
