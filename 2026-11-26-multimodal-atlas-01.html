ATLAS 多模态图谱
NO.01  /  2026-11-26
Multimodal Atlas · 第 01 期

能看、能听、能生成，今年已经不是同一张考卷

过去十二个月，「多模态」被拆成了三件完全不同的事：把图看懂、把话说顺、把片子做出来。它们的榜单不同、成本单位不同、失败方式也不同。 这一期把 Qwen、GPT、Gemini、Seed / Seedance、MiniMax、GLM、Kimi、DeepSeek 摆在一张桌上，只回答一个问题：你手上这件活，该交给哪一条线。

01

本期三个判断

先把结论放前面。三条判断后面都有对应证据，不同意可以直接看数据那节。

JUDGMENT 01

「多模态」已经裂成三张考卷，混着比是今年最贵的错误

理解侧考 MMMU-Pro 和 OCR，实时交互侧考首包延迟和双工，生成侧考 Elo 和每秒成本。这三件事没有可比性，但市面上大量文章把它们塞进同一张「多模态能力表」。

一个典型误判：看到 Seedance 2.5 在图像生视频榜排第一，就以为它能读图里的合同条款。它不能——它是生成模型，输入里的图只作为参考素材，不产生「理解结论」。反过来，GPT-6.1 Terra 的 MMMU-Pro 能到 85.5%，但它一张图也画不出来。

选型第一步不是看榜，是先确定你要的是「读」「说」还是「产」。三者的预算科目都不一样：读按 token，说按并发和延迟，产按秒。

JUDGMENT 02

前沿在 Google，交付在中国厂商——这条分界今年更清楚了

Google 拿出的东西是「模型本身能吃什么」：Gemini 4 Argon 原生接收文本、图像、音频、视频、PDF，LVBench 91.7%，一段纯音频能反推画面。这是研究意义上的强，但它仍然是 API 里的一个能力，不是一个能直接卖给工厂的产品。

中国厂商这半年做的几乎都是「最后一百米」：Qwen3-VL-Plus 直接对着工业质检和百万级图纸批量解析，配套轻量化 SDK 对中小企业免费开放商用；Seedance 2.5 把单段拉到 30 秒 4K，还给了 480p 草稿模式先验分镜；MiniMax H3 把 2K 生成价压到约同类旗舰的三分之一。这些不是跑分，是报价单。

要能力上限看 Google，要能签合同的交付看阿里、字节、MiniMax。两者的评价标准不该是同一个。

JUDGMENT 03

权重在贬值，模态覆盖在升值

OpenAI 这一代反而收窄了：官方模型页上，GPT-6 Astra 与 GPT-6.1 Terra 的输入模态只有文本和图像，音频与视频不在列——想处理得靠工具链绕。这是工程上的克制，但也意味着「一个模型全吃」在闭源阵营并不成立。

开放权重这边是反过来的：Qwen 一条线同时有 VL（看懂）、Omni（听说）、Qwen4（原生视觉基座）；MiniMax 有 H3（生成）+ M3（文本）+ Speech 2.8 / Music 3.0；智谱有 GLM-4.6V 的 106B 和 9B 两档。能下载，就意味着能私有化、能微调、能把 badcase 喂回去。

要私有化，「能不能下载」比「排第几」重要；只要 API，「模态表」比「参数量」重要。

真正的新东西

Terra 的定位不是「更小的旗舰」，而是把视觉判断接到动作上：读技术图纸、匹配商品目录、填表单、编辑视频。官方给的对照是，中等推理强度下 Agents' Last Exam 比上一代 Terra 高 15 个百分点，达到同等成绩的单任务成本约三分之一；OSWorld 2.1 上超过了 GPT-5.6 Terra 的最高分。

真正的新东西

原生是真的原生：一段 MP3 能分析编曲、配器、情绪并倒推提示词；一段纯音频能反推画面结构。这类任务在「ASR 转写 + LLM」的拼装链路上做不出来，因为信息在转写那一步就丢了。另外它把长解码做到与窗口同量级，跨请求接续，专治 Agent 长任务的超时断流。

真正的新东西

它是一个「全模态生成」而不是「视频 + 配音」：输入可以是文字、图、视频、音频的任意组合，输出是带原生双声道音效的片段，对白稳定支持 11 种语言。工程上最巧的一手是把 13B 参数放进 AdaLN 分支，推理时可以预计算缓存、不必加载——社区那些「pruned」权重就是把这部分去掉了。

注意

真正的新东西

「原生多模态 function calling」这句话大部分厂商都在说，GLM-4.6V 是少数把机制讲清楚的：图像和截图能作为工具输入直接传下去，工具返回的视觉结果（图表、渲染页面、搜索结果图）会被解析回推理链。加上 9B 的 Flash 档可以本地跑，它是私有化多模态 Agent 目前最现实的一块积木。

06

三种融合方式，三种代价

「多模态」在架构上只有三种做法。选哪种不取决于先进程度，取决于你的瓶颈是细节、延迟还是时长。

08

按任务选，不按榜选

六个真实场景，每个给一个首选和一个备选。备选存在的理由通常是价格、私有化或合规。

长视频 / 会议 / 课程录像
Gemini 4 Argon · Kimi K3.1 Pro
要连音频里的语气一起判断，只有 Argon 是真原生；只要画面 + 时间定位，Kimi 的 1M 窗口更便宜。两者都别信 85+ 的旧协议分数。
图纸 / 文档 / 工业质检
Qwen3-VL-Plus · GLM-4.6V
Plus 直接对着百万级图纸和倾斜文档 OCR，还配免费 SDK；要私有化就上 GLM-4.6V 的 9B 档。只抽文字用 OCR 专用模型，便宜十倍。
实时语音助手 / 客服
Qwen3-Omni（自建 / API）
230ms 级首包 + 可开源，是唯一能自己改的项目；API 版支持 74 种语言、39 种中文方言。Gemini 那条线输入有音频但输出只有文字，做不了全双工。
屏幕操作 Agent
GPT-6.1 Terra · GLM-4.6V
Terra 是把视觉判断接到动作上训的，OSWorld 2.1 有明确提升；GLM 的原生 function calling 让截图能直接当工具入参，适合自建闭环。
广告片 / 短剧 / 社媒素材
Seedance 2.5（质量）· MiniMax H3（成本）

口径，以及我没敢写成事实的部分

这个栏目的原则是：数字必须能追到出处，追不到就标成「待确认」。多模态这一块比纯文本模型更容易看错，原因有六条。

  1. 同一张榜，三个第一名。MMMU-Pro 在三个汇总站上分别把 GPT-6.1 Terra（85.5%）、GPT-6.1 Sol（85.95%）、Claude Opus 5.5（87.7%）排在第一。差异来自版本、思考档位和是否带工具。本文取 11/21 那份，并注明它也是厂商自报。
  2. 视频评测的帧预算不一致。Qwen3-VL 的技术报告写明给自己 2048 帧，Gemini 512、GPT-5 256、Claude 100（受 API 限制）。这个对比不公平，官方自己也承认。
  3. 旧协议系统性高估。Video-MME v2 严格协议下，人类 90.7、最强闭源 49.4、最强开源 39.1；旧协议被估计整体高约 17 分。凡是看到「视频理解 90 分」，先问协议。
  4. GPT-6 Astra 的模态有冲突说法。官方模型页只列文本与图像；有研报与二手文章称支持音频、视频实时联合解析。本文按官方口径记，并把它标为待确认。
  5. 生成模型的「每秒成本」不含返工。Seedance 的 $34.12/分钟与 H3 的 $4.80/分钟都是输出计价，实际项目里还要乘上废片率。废片率没人公开，只能自己测。
  6. 榜位每周变。视频生成的 Elo 榜尤其如此，本文引用的是 11/17–11/18 的快照。做预算时请重读一次，不要把快照当长期结论。

另外三处本文主动没写死：Qwen3-Omni-Flash 的具体价格（官方只说「显著下降」）、H3 的「11 月 10 日首次发布」说法（官方许可落款是 8 月 2 日，不采信二手日期）、MiniMax H3 与 Seedance 2.5 的图生视频 Elo 直接可比性（H3 未公开 Elo，只能记榜位）。
